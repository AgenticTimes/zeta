# Python stdlib shim registry (data-driven) — read at compile time via
# include_str!, so adding a library means editing THIS file, not Rust.
#
# Format (one entry per line, '#' starts a comment):
#   M <module>                         declare a module
#   A <module> <alias>                 extra accepted import alias
#   F <module> <member> <symbol> args=<n|f64[,f64...]> ret=<i64|f64|void> [handle=<Tag>]
#                                      module-level member -> runtime shim
#   W <handle> <method> <symbol> args=<n> [ret_handle=<Tag>]   (n includes the receiver)
#                                      method dispatch for a handle tag
#
# `handle=<Tag>` / `ret_handle=<Tag>` is what makes t.start() / f.result()
# dispatch exactly instead of by guessing method names.
