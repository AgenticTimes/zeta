# 轴 B 立项：值标签（Tagged Values）——i64 槽双义表示的根治

> 立项日期：2026-10-06（批 1010 落稿）。主计划原文：refactor.md §2（B.0–B.5），
> 本文档是该节的**立项执行版**：补充 2026-10 实测数据、细化里程碑（M1–M5）、
> 明确验收判据与风险预案。批准后按里程碑排批，每批独立提交、独立回滚。

## 1. 问题（B.0 重述＋本会话新增实证）

编译器 ABI 里一个 64 位槽承载：整数、浮点位模式、字符串指针、容器句柄、
struct 句柄、JSON tag 单元。**值不带类型**，静态类型传不到的分派点只能
运行期"猜形状"。复发病灶固定两句话：**值是对的，类型丢了**。

refactor §2 表列的批次证据（279/282/283/296/297/298/299）之外，
本会话（批 963–1009）新增实证：

| 新实证 | 断点 | 批 |
|---|---|---|
| keyfn 桥 f64 数组走位桥（bitcast）、i64 数组走 sitofp 桥——**每个消费点必须静态知道槽语义**，两桥选错即静默错值/比较全错 | `py_max_key_f64` vs `py_max_key_i64_f64` | 983–989 |
| `len(list([...]))` dest 槽零 store 读栈垃圾，O3 寄存器分配掩盖——未定义槽与优化级别交互出**随级别翻转**的错值 | call_builtin.rs passthrough | 1007 |
| `read_text` 返回值（str）落 `println_i64` 打指针——PyPath handle 方法链的返回域推断缺失 | t73（在册 KNOWN-FAIL） | 1006 |
| 函数签名表 W0912 元数核对咬出 13 条注册表/C 漂移——签名类错误的根治项与值标签同源（类型面单一事实来源） | signature_table | 991/997 |

## 2. 债务现状（2026-10-06 复测 ref B.1 基线）

| 度量 | 2026-09-21 | **2026-10-06** | 趋势 |
|---|---|---|---|
| `GC_base` 探针引用（py_additions + tokio_stub） | 11 + 2 | **16 + 3** | ↑ 恶化 |
| `__asm__` 魔法名分派（py_additions） | 3 | **4** | ↑ 恶化 |
| 指针区间猜测（0x100000000 等） | 2 | 在册（同上文件） | 持平 |

**结论**：轴 B 拖延的每一天都在按同斜率积累启发式探针——B.1 表"幸存者
不是设计"的原话持续被新批次验证。这是立项的时效性依据。

## 3. 已在役的三个先例（B.3，非从零发明）

1. **ZJ_* tagged cell**（`tokio_runtime_stub.c` `zj_make(tag, payload)`，
   16 字节 GC 块，7 种 kind）：JSON 域全链路零启发式——运行期 tag 可行性
   的实机证明。
2. **registry handle 标签**（`pylib/registry.txt` `handle=<Tag>` ＋
   `handle_tag()`）：threading/Path/Date 全家精确分发，"dispatch exactly
   instead of by guessing"。
3. **字典值侧表**（`DictInsert` 记静态类型 0-3 到侧表）：受限标签已在役，
   代价（类型动态变化即失效）即 D 方案要解的部分。

## 4. 选型（B.4 定案：分层混合 D）

方案 A（全量 tagged cell）/ B（GC 块头加 tag）/ C（纯编译期）的否决理由
见 refactor §2 B.4 表——维持原判。**执行 D：静态层修传播＋动态层只给
边界值打 tag（复用 ZJ 16 字节格式），探针保留为兜底渐进退役。**

## 5. 里程碑（M1–M5，每步独立提交＋独立回滚＋三基线全程不红）

### M0 边界点清单（0.5 天，先行）
- 用 `--dump-mir`＋`grep PyDynamic` 全语料扫描，产出 **PyDynamic 流动
  边界清单**（F.3 与 B/T3 的握手点）：`dict[str, Any]` 写入/读出、未标注
  形参实参、json 取值、DataFrame 单元格、推导式闭包参数。
- 产物：docs/axis-b-boundaries.tsv（边界点 × 触发语料 × 现行分派函数）。
- **验收**：清单覆盖 ref §2 B.1 表全部 10 个探针的调用面。

### M1 静态层：bool 掩码语义（1 天）
- MIR 引入 `DynamicArray(Bool)`：掩码粗定型点、行过滤分派判据、
  codegen `container_cond_i1` 全改读类型。
- 验收：`df[bool_vec]` 转正（ref 试金石之一）＋python_style 补覆盖用例。

### M2 静态层：跨函数签名传播（1-2 天，与轴 F.2 合批）
- 函数签名入符号表，替换 mangle 名字符串匹配；未标注形参记 PyDynamic
  不再默认 I64。
- 本会话已铺路：signature_table（批 990–997）证明"单一事实来源＋机器
  核对"模式可行，M2 是同一模式在编译期类型面的推广。
- 验收：gen.rs 侧信道墙（array_lit_lens 等六条）逐条删除，MIR diff 为空。

### M3 动态层：tagged cell 进 ABI（2-3 天，风险最高段）
- `zj_make` 16 字节格式推广为动态值通用表示；先 JSON 域外的第一个域：
  `dict[str, Any]` 写入/读出（探针调用面最大的域）。
- 验收：`zeta_dyn_len`/`zeta_dyn_contains`/`zeta_dyn_truth` 三探针在该
  域退役（B.1 表 −3 行）；试金石**元组 `in`**（279 残留）转正。

### M4 动态层：边界装箱全覆盖（2-3 天）
- M0 清单逐域装箱（DataFrame 单元格、json 取值、推导式闭包参数）。
- 验收：`GC_base` 探针引用 ≤5（2026-09 基线 13→现 19 的斜率逆转）；
  `__asm__` 魔法名归零。

### M5 探针退役＋判据闭合（1 天）
- B.1 表逐条删除或降级为 `unreachable!()` 式断言；基线度量归零。
- 验收＝轴 B 完成判据（ref §10）："B.1 基线度量归零、MirGen 侧信道六条
  删除、试金石（元组 in）与 df[bool_vec] 转正"。

## 6. 风险与预案

| 风险 | 预案 |
|---|---|
| M3 装箱破坏与裸 i64 域互操作（JSON 教训：tag 值与探针值同 ABI 不兼容） | 每域独立灰度：装箱点两侧同批切换，跨域值维持裸表示 |
| GC 压力（16 字节 cell × 动态值数量） | 基准：`tools/perf_baseline.py` ir/aot 两口径，M3 合并前后对照；超 5% 即回退改仅"逃逸值"装箱 |
| 边界点找不全 | 探针兜底不删（M5 才删），发现漏网先补清单再迁 |
| 与 t425 共享格合同/NoneValue 推断层耦合 | M2 完成后重估两者（M2 的签名传播会缩小两者的暴露面） |
