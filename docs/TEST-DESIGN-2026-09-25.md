## 一、Seam 提案（测试观察点，待确认）

编译器的"公共接口"不是函数签名，而是**用户与门禁实际经过的观察面**。七个候选 seam，前四个已有基础设施：

| # | Seam | 观察方式 | 既有设施 | 适用用例族 |
|---|------|---------|---------|-----------|
| S1 | **编译并运行整个程序** | `stdout` 逐字 + 退出码 | tests/python_style（`// expect` golden，t4xx 段） | 语义对齐、静默错值哨兵、桩行为 |
| S2 | **CLI 合同**（`zetac <args>` 的 stderr 诊断 + 退出码） | 诊断文本 + rc | `tools/cli_semantics_check.sh`（18 断言，门禁第 12 步） | 降级链、CLI 五小项 |
| S3 | **MIR 规范形** | `--dump-mir` canonical 文本 | `tools/mir_diff.sh`（逐字节稳定） | lowering 不变量、确定性 |
| S4 | **符号存在性** | `nm -gU` 对 registry ↔ .o | `tools/check_registry_symbols.sh`（0/1/2 三态） | 绑定契约、幽灵符号 |
| S5 | **CPython 差分** | 同源码在 zetac 与 `python3` 各跑一遍 | G.3 计划（`tools/diff_test.py`，未建） | PY-A 对齐族、锁步族 |
| S6 | **解析完全性报告** | W1002 的行数/偏移文本 | `truncation_inventory.sh` / `parse_bisect.py` | 截断族回归（只许减少） |
| S7 | **优化级别矩阵** | `opt_matrix.sh` 的翻转计数 | 已建（批次 307） | 全级别语义一致 |

**oracle 独立性原则**（反同义反复）：S1/S5 的期望值来自 CPython 实跑输出或手工核算字面量（如 `-7 // 2 == -4`），**绝不**从被测编译器的行为推导；S3 的期望值来自"改动前后逐字节相同"这一自证（重构用）或独立写的 canonical 样例。
